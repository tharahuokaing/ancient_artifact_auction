# Ancient Artifact Auction & Research Study

> **Author:** Research Study by Huokaing Thara
> **Location:** Phnom Penh, Cambodia | **Est.** 2023

Welcome to the **Ancient Artifact Auction** web platform repository. This project is a curated digital exhibition, research catalog, and bidding system showcasing historic Southeast Asian ceramics, sacred metalwork, and regional art replicas.

## 📌 Features

* **Interactive Bidding System:** Dynamic bid evaluation and placement interface.
* **Detailed Historical Catalogs:** Comprehensive descriptions covering material, morphology, origin, dating, and commercial valuations.
* **Responsive Layout:** Clean CSS grid and card components designed for seamless browsing on desktop and mobile.

## 🛠️ Tech Stack

* **HTML5:** Semantic structural layout.
* **CSS3:** Custom styling and card component layout.
* **JavaScript (ES6):** Client-side bidding logic and user interactions (`script.js`).
## 🚀 Quick Start

1. **Clone the Repository:**
git clone https://github.com/your-username/ancient-artifact-auction.git

2. **Navigate to the Project Directory:**
cd ancient-artifact-auction

3. **Open in Browser:**
Simply open `index.html` in your preferred web browser to view the interface.
